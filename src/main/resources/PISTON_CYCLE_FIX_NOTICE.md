# ChimeraClient 2bPiston CycleFix — 1.21.11

入力は、この会話で作成した最新の `Chimeraclient-MioRender-HUD-1.21.11.jar`。
今回はユーザーの依頼に基づき、Shoreline からそのまま移植した段階処理を独自に再構成しています。
CrystalAura、Mio Render/HUD、GUI、Font、登録、既存の Mixin / リソースは変更していません。
差分は TwoBPiston と新規 PistonCycle / AlienPlaceAnimation、追加の変更告知・Alienライセンスのみです。

## 原因と変更

- `selectionValid()` と `placePiston()` が隣接レッドストーンを無条件に拒否していたため、通電源があると開始できませんでした。
  この除外をなくしました。ブロック・衝突・自分を通るルートの安全判定は残しています。
- 既存通電源があり、ピストン本体とクリスタルの当たり判定が重ならない場合:
  **クリスタル設置 → 出現確認 → ピストン設置 → 押し出し確認 → 攻撃**。
  既存レッドストーンの上面を優先してクリックし、その上にピストンを置けます。
- 通電源がない通常の配置:
  **ピストン設置・応答確認 → クリスタル設置・出現確認 → 通電 → 押し出し確認 → 攻撃**。
  先に通電してからクリスタルを置く分岐は削除しました。
- ピストンがすでに伸びている、または先にクリスタルを置くと本体の設置が衝突で拒否される配置は、
  **通電源採掘 → ヘッド復帰 → 配置 → 通電** の順です。Minecraft の設置衝突制約を無視する実装ではありません。
- 生きたクリスタル・伸びたヘッドを「元の空気マスがなくなった＝無効なプラン」と判定して途中放棄しません。
  ワールドの観測結果で状態遷移する `PistonCycle` を分離しています。
- 攻撃送信だけでは爆発済みと扱いません。追跡した同じエンティティIDの削除まで再攻撃します。
  採掘中にも攻撃を再試行できます。押し出した後の一時的なピストンヘッド遮蔽による damage < 1 の拒否を削除しました。
  攻撃直前には対象クリスタルへの silent rotation を送ります。通常の攻撃リーチ制限は残しています。
- 採掘の START と進捗計算と STOP でツールが一致するよう修正。
  サーバー用 sequence 番号を付け、実 tick と推定サーバーTPSに合わせて進捗を積み上げます。低TPS時の早過ぎるSTOPを抑えます。
  ローカルのブロックを偽の空気にしません。
  STOP の応答がない場合は START から正規の採掘を再試行します。以前の3回の STOP 後に止まる処理は廃止しました。
- レッドストーンの所有フラグだけで採掘を止めず、選んだピストンに隣接する実際のレッドストーンブロックを解除します。
  周囲一帯の無関係なレッドストーンを探索して破壊する処理ではありません。
- 使用済みピストンが1個あるだけで新しい配置を禁止する上限と、正常完了後の再走査待ちをなくしました。
  爆発・通電源撤去・ヘッド復帰が確認できれば、適合する同じピストンを再利用して次のクリスタルを開始します。
  ターゲットが0.5ブロックを超えて移動した場合やルートが失われた場合は再探索します。
- MovingPause は水平速度のみを見るよう修正しました。縦速度・重力だけでは「移動中」としません。
  通電後の押し出し確認・攻撃・撤去・応答待ちは移動中でも継続しますが、次の新規配置は SelfGround / MovingPause に従います。

## 設定と使い方

名前は引き続き Combat の `2bPiston`。既存の設定名は保存互換のため残しています。
独立した「状態」を使うため、旧 Stage / ～Stage / ～MaxStage は動作順序の指定には使いません。
通常の連続サイクルでは `MaxSpeed=ON`, `ConfirmPush=ON`, `InstantBreak=ON`, `PowerCleanup=ON` を使用します。
`2b2t-Mode=ON` かつ `PowerCleanup=OFF` は、爆発確認後に通電設備を残して別ルートを探す旧オプションを維持しています。
通常モードでは同じピストンを再利用するため、PowerCleanup=OFF でも再通電に必要な撤去を行います。
設定された CycleDelay / PlaceDelay は MaxSpeed=OFF の場合に適用します。
RestartDelay を短縮するだけの変更ではなく、正常サイクルは再始動待ちを挟まない構造です。

ピストン・クリスタル・必要なレッドストーン・黒曜石・採掘用ツールはホットバーに用意してください。
既存の InventorySwap はホットバーの silent slot 切り替えであり、メインインベントリからの取り出しではありません。
既存通電源はレッドストーンブロックを対象としています。回路・レバー・トーチの自動改造はしません。
サーバーが禁止する空中設置、届かない攻撃、採掘速度を突破することは保証しません。
固いブロックの採掘時間、ping、サーバー側のピストン更新は実際の確認待ちとして必要です。
`Debug=ON` で現在の状態、送ったアクション、SelfGround / MovingPause / NoEating などの停止理由を表示します。
HUD のモジュール情報にも状態（Scan / CRYSTAL_FIRST / PUSH / CLEANUP 等）が出ます。

## Alien の設置表示

添付 `alien-v4-main.zip` の PistonCrystal 自体には描画コードがありません。
PistonCrystal → BlockUtil.placedPos → ThreadManager → PlaceRender の共通設置表示が元実装です。
これを **2bPiston の設置だけ** に限定して実装しました。Alien の combat ロジックに置き換えてはいません。
黒曜石・ピストン・レッドストーンの設置試行を描画します。元実装同様、クリスタルエンティティのESPではありません。

2bPiston を右クリックして以下を変更できます。

- `Render`: 描画ON/OFF。
- `FadeTime` / `TimeOut`: 成功時のアニメーション・設置応答待ちの表示時間（ms）。どちらも元実装の既定値500。
- `RenderMode`: Fade / Shrink / All。既定値All（フェードと中心への縮小）。
- `Ease`: 添付の22種類を移植。既定値CubicInOut。
- `Box` / `BoxColor`, `Fill` / `FillColor`: 成功表示の枠と塗り。白枠・白の半透明塗りが既定値。
- `TryPlaceBox` / `TryPlaceBoxColor`, `TryPlaceFill` / `TryPlaceFillColor`: 応答前の灰色枠・赤系半透明塗り。
- `NoFail`: ONなら応答前の専用表示をせず、試行時点から通常のフェード。

描画APIは1.21.11の既存Chimera/MioRenderへ適合。枠の太さ1.5と元のRGBA値を保持しています。
元のPlaceRenderが失敗エントリを永続保持する点は修正し、TimeOutで破棄します。
Back系イージングのオーバーシュートは無効なBox/アルファを作らないよう0〜1に制限しています。
描画キューは128件に制限し、OFF・ワールド切替で消去します。失敗時の描画が設置を成功扱いすることはありません。

## 検査

Minecraft 1.21.11 へのメンバー参照検査、既存エントリのバイト比較を実施。

## SRC / 再ビルド

追加・変更コード、テスト、ビルドツール、入力 JAR を同梱したオーバーレイ開発キットです。
以前の Mio Render/HUD SRC も `reference/` に同梱します。Chimera 全体のオリジナル SRC ではありません。
zsh / JDK 21以上 / ローカルの Gradle・Fabric Loom キャッシュを使い `zsh build.sh` で再ビルドします。
外部ダウンロードは行いません。キャッシュがない場合は `NAMED_MC`, `INTER_MC`, `MAPPINGS`, `TR`, `DEPS` に
Minecraft 1.21.11 / Yarn 1.21.11+build.6 / TinyRemapper 0.14.1 / コンパイル依存の正確なパスを指定してください。
`BASE_JAR` / `OUT_JAR` / `ALIEN_ZIP` も指定可能です。元 JAR のライセンス・告知はそのまま保存しています。
