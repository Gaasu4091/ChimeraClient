# Shoreline core / rotation integration rebuild

Baseline is the supplied Shoreline 1.5 jar, not the previous independently modified CrystalAura. AutoCrystal attack, placement, selection, yaw-step, inhibition, sequential and stuck handling are restored from its named-decompiled source. The supplied timer's original nanosecond behavior is restored as well. No SilentRotate setting, one-second quarantine, wrapped-yaw helper, custom delayed-attack priority, or speculative-deletion removal is applied to this baseline. Those previous changes are not silently retained. The original may retain its own limitations/bugs; restoring its behavior is not a guarantee of operation on every server.

The original Rotation and RotationManager request queue, priorities, request replacement, movement consumption, sensitivity handling and server angles are copied into the relocated package. Direct event-bus subscription is replaced by Chimera/1.21.11 hooks. Player calculation runs before AbstractClientPlayerEntity.tick, rather than Chimera's tail module tick. Frame RunTick runs before rendering. Movement packet yaw/pitch expressions use the selected request, including vanilla last-sent angle bookkeeping, without changing the camera or sending the old standalone look packet on each request. PlayerInput and packet horizontalCollision differences are API adapters. MovementFix, mouse sensitivity fix and PreserveTicks controls use Shoreline defaults under Client → ShorelineRotations. Disabler-specific yaw-overflow integration and Anticheat's optional web-jump toggle are not transplanted; there is no matching Chimera module. Those are not described as full-client transplantation.

Gui/Font and original PistonCrystal are retained. GeometryFix: 2bPiston no longer invokes the complete private Chimera planner, which also inherits unrelated start/mining/support conditions, including an early exit when the target's upper levels are surrounded. Instead, Normal/Long/LongSide position equations are explicitly extracted and enumerated independently of the world. Air and ground layouts are both eligible; Homovore placement, collision, damage and reach validation still decide whether a layout is usable. The supplied pattern source is the reference for the coordinate equations. The geometry enumeration is not a claim to preserve every original Chimera mining/start-state behavior; intentionally only layout geometry is reused, as requested. Target-block geometry is cached, and equal explosion/base damage calculations share a per-selection cache. The debug reason reports the deepest validation stage reached instead of an arbitrary last candidate's shallow rejection. Actual in-world successful placement remains unverified.

This is a patch-source distribution, not a standalone Gradle project. The original sources used for baseline comparison and compatibility source are supplied. Verification covers compilation, member resolution, event hook targets, no direct camera mutation in the original queue-submission path, and offline request consumption. Live gameplay, rollback, attacks and rendering remain unverified. Replace the old Chimera jar; do not run multiple Chimera versions together.
